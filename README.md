# Opporlligence

**Opportunity Intelligence for a changing world.**

Opporlligence is an intelligence system designed to monitor real-world developments, understand what changed, connect developments across time and domains, detect gaps, and surface evidence-backed opportunities for investigation.

## The core idea

News and social media are **inputs**, not the product.

The system asks:

> **What changed in the world, what does that change make possible, and what is now missing?**

It is intentionally not limited by the user's current technical skills. Capability affects how an opportunity may eventually be pursued, but it does not define what the system is allowed to discover.

## Intelligence loop

```text
REAL WORLD
    ↓
Information sources
    ↓
Events & developments
    ↓
Change detection
    ↓
Historical/contextual analysis
    ↓
Gap discovery
    ↓
Opportunity generation
    ↓
Evidence + contradiction testing
    ↓
Opportunity ranking
    ↓
Human investigation
    ↺ feedback / memory
```

## Design principles

- **World first, user second.** Discover what matters before asking how the user can participate.
- **Evidence over novelty.** A clever idea without evidence is not an opportunity.
- **Historical memory.** Current developments must be understood against what existed before.
- **Convergence.** Important opportunities may emerge from several seemingly unrelated developments.
- **Self-criticism.** Every opportunity should be challenged and given a plausible disproof condition.
- **Opportunity memory.** Opportunities can evolve, decay, strengthen, or disappear.
- **No forced ideas.** The system may return `INSUFFICIENT_EVIDENCE`, `MONITOR`, or `IGNORE`.
- **Explainability.** Every surfaced opportunity should be traceable to evidence and reasoning.

## Initial scope

Version 0 starts with Zimbabwean information and a small, controlled set of sources. The architecture is intended to expand beyond Zimbabwe and beyond news into government announcements, company/product changes, developer discussions, regulations, jobs, market shifts, technology releases, and other signals.
