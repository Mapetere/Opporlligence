# Roadmap

## V0 — Prove the intelligence loop

Goal: prove that Opporlligence can move from information to a defensible opportunity proposal.

- [ ] Define canonical data models.
- [ ] Create source ingestion interface.
- [ ] Normalize source records.
- [ ] Extract events and changes.
- [ ] Add historical/context retrieval.
- [ ] Generate candidate gaps.
- [ ] Generate candidate opportunities.
- [ ] Run contradiction checks.
- [ ] Rank and explain opportunities.
- [ ] Produce a simple CLI report.

## V1 — Persistent intelligence

- [ ] Store events and opportunities.
- [ ] Track opportunity state over time.
- [ ] Detect related developments.
- [ ] Add source reliability signals.
- [ ] Add opportunity decay/evolution logic.

## V2 — Multi-domain intelligence

- [ ] News.
- [ ] Government/regulatory signals.
- [ ] Company/product changes.
- [ ] Developer ecosystems.
- [ ] Job-market signals.
- [ ] Technology releases.
- [ ] Social/community signals.

## V3 — Adaptive intelligence

- [ ] Learn which signals are useful.
- [ ] Learn which opportunities survive validation.
- [ ] Discover new reasoning lenses.
- [ ] Improve alert thresholds.
- [ ] Build a richer world knowledge graph.

## V4 — Autonomous opportunity monitoring

The system continuously observes, reasons, validates, remembers, and surfaces only developments and opportunities that cross meaningful significance thresholds.

The roadmap is deliberately subordinate to evidence. If an architectural assumption proves wrong, the roadmap should change.
